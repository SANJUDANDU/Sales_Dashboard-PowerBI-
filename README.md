🌊 Sales Dashboard (Power BI)

An interactive Power BI dashboard designed to analyze sales performance, track key metrics, and uncover meaningful insights about customers and products.

🚀 Project Overview

This dashboard provides a clear view of business performance by transforming raw sales data into interactive visual insights.

It helps answer questions like:

How are sales trending over time?
Which products are performing best?
Who are the top customers?
What categories drive the most revenue?
📊 Features
📈 Sales trend analysis (monthly/yearly)
🧑‍🤝‍🧑 Customer insights and segmentation
🛒 Product category performance
📦 Order-level analysis
🎯 Key KPIs:
Total Sales
Total Orders
Average Order Value
🗂️ Dataset

The dataset includes two main tables:

Customers → customer details (name, location, score)
Orders → transaction data (date, product, quantity, sales)
🧩 Data Model
One-to-Many relationship:
customers.customer_id → orders.customer_id
